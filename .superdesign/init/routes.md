# App Routes

- `/` — Home page redirecting to `/chat` (`src/app/page.tsx`)
- `/chat` — AI Chat interface (`src/app/chat/page.tsx`)
- `/translator` — Translator workspace with Datamuse synonym suggestions (`src/app/translator/page.tsx`)
- `/admin` — Admin Settings form (`src/app/admin/page.tsx`)
- `/api/chat` — AI streaming endpoint (`src/app/api/chat/route.ts`)
- `/api/synonyms` — Synonym proxy route for Datamuse API (`src/app/api/synonyms/route.ts`)
